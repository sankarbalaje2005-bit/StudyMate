# StudyMate ⚙️📚

StudyMate is an AI-powered Mechanical Engineering study assistant built using Streamlit and Google Gemini.

## Features

- Ask Mechanical Engineering questions
- Solve numerical problems step by step
- Analyze engineering images
- Identify mechanical components
- Explain working principles
- Generate 2-mark, 5-mark, 8-mark and 10-mark exam answers
- Generate revision summaries
- Telegram bot support

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-telegram-bot
- GitHub

## Mechanical Engineering Topics

StudyMate can help with:

- Engineering Mechanics
- Thermodynamics
- Thermal Engineering
- Fluid Mechanics
- Heat Transfer
- Manufacturing Processes
- Metrology
- Machine Design
- Design of Machine Elements
- CAD
- Engineering Drawing
- Theory of Machines
- Engineering Materials
- Maintenance Engineering
